# KB-1058: Brightwick Drive Sync Problems

Applies to: Employees with a company laptop
Owner: Collaboration Services | Last reviewed: 2026-06-10

## About Brightwick Drive
Brightwick Drive is the company's cloud file storage. Each user has 1 TB of storage. The sync client keeps chosen folders in step between your laptop and the cloud.

## Limits that stop files syncing
- The full file path cannot be longer than 400 characters.
- Single files larger than 250 GB are not supported.
- These characters are not allowed in file names: " * : < > ? / \ |

## Sync is stuck
1. Check the Brightwick Drive icon in the taskbar to confirm you are signed in.
2. Pause sync and resume it.
3. Make sure the laptop has free disk space. Use Files On-Demand to keep large files in the cloud only.

## Deleted files and versions
Deleted files stay in the Brightwick Drive recycle bin for 93 days. Each file keeps its last 100 versions, so you can restore an earlier version yourself from the file's version history.

## Sharing outside Brightwick
Only Internal and Public files can be shared externally. Confidential files need manager approval before they are shared outside the company, and Restricted files must never be shared externally through Brightwick Drive.

## Files outside Brightwick Drive
Files saved only on the laptop, outside Brightwick Drive folders, are not backed up. Keep work files in Brightwick Drive.
