# KB-1027: How to Report a Phishing Email

Applies to: All employees and contractors
Owner: Security Operations Center (SOC) | Last reviewed: 2026-08-19

## Use the Report Phish button
If an email looks suspicious, select Report Phish in the mail client. The button is available in the desktop app and the web client. It sends the email to the Security Operations Center and removes it from your inbox. Do not forward suspicious emails to colleagues or to the IT Service Desk, because forwarding spreads the attachment or link.

## Warning signs
- A sender address that is not on brightwick.example, the only internal email domain.
- Urgent requests to pay an invoice, change bank details or buy gift cards.
- Links whose web address does not match the text shown.
- Unexpected MFA prompts, or messages asking for your MFA code.

## If you clicked a link
If you clicked a link but did not enter anything, report the email with Report Phish and close the browser tab. No other action is needed unless the SOC contacts you.

## If you entered your password
1. Change your password immediately in MyAccess.
2. Call the IT Service Desk and say "possible credential compromise".
3. The service desk logs a P2 security incident, and the SOC signs you out of all sessions.

## If you opened an attachment or approved an unexpected MFA prompt
Disconnect the device from the network by turning off Wi-Fi or unplugging the cable. Do not power off the device, because the SOC may need its memory for the investigation. Call the IT Service Desk immediately.

Never approve an MFA prompt you did not start yourself.
