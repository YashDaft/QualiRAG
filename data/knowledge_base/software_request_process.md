# KB-1066: Requesting New Software

Applies to: All employees
Owner: IT Asset Management | Last reviewed: 2026-04-29

## Check the Software Portal first
Most business software can be installed straight from the Software Portal without a ticket or approval.

## Software that is not in the portal
1. Submit a "New software request" in ServicePoint with the product name, the business reason and how many people need it.
2. Your manager approves the request.
3. IT Security reviews the software. The review target is 10 business days.
4. IT Asset Management arranges the licence.
5. The software is packaged and added to the Software Portal for installation.

Free and open-source software follows the same process and still needs a security review.

## Browser extensions
Only extensions on the approved list can be installed. Ask for an extension to be added through the same request process.

## Administrator rights
Administrator access is not granted simply to install applications. Developers who need elevated rights for their work can request time-limited elevation through the Privileged Access tool. It needs manager approval and lasts a maximum of 4 hours per request.

## Unused licences
Licences that have not been used for 90 days are reclaimed and the software is removed.
