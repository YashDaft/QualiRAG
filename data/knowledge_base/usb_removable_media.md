# KB-1045: USB Drives and Removable Media

Applies to: All company laptops
Owner: Security Engineering | Last reviewed: 2026-05-05

## Default setting
USB storage devices are blocked on company laptops for both reading and writing. Keyboards, mice, headsets and docking stations still work normally.

## Encrypted USB drives
If you have a business need to move data on removable media, request a company-issued encrypted USB drive through ServicePoint. The request needs manager approval and a Security review. Approval lasts 12 months and must then be renewed.

## Restricted data
Restricted data must never be copied to any USB drive, including an encrypted company drive.

## If an encrypted drive is lost
Report it as a security incident immediately, and no later than 1 hour after you notice, by calling the IT Service Desk.

## Better alternatives
- Share files internally with a Brightwick Drive link.
- Send files to external partners through the secure file transfer service, which records who downloaded each file.
